## Method

Pure scoring schema version 1, engine EcoSignal-Unified-Provisional-v2.0.0, explicit configuration records. Weights: satellite .35, AQI .15, coverage 1/6, growth form 1/12, geomorphology .25. Biology is ONE domain. Satellite = .45 inverted NDVI(.2,.8) + .35 inverted NDMI(-.2,.5) + .20 BSI(-.3,.3), clamped 0–100. AQI =100*clip(AQI/300). Coverage inversion is provisional. Raw confidences are displayed separately; they are not calibrated scientific quality or overall confidence.

Growth-form ordering is **disabled** because its general ecological validity is unsupported. The reserved 1/12 weight is not redistributed. Full score requires all four domains and both biological subinputs; therefore currently no user can receive a full score. No partial total is published. Eligible component values and nominal weight coverage are displayed with missing inputs. Complete-score comparisons remain empty. No example location or notebook measurement becomes a real observation. Zero-weight inputs do not count or block explicit analysis scenarios; analysis configuration is separately marked.

GeoRisk sampling must come from true numerical georeferenced 2024 raster data and a fixed, versioned source cohort CDF with >=100 finite sorted values, raster SHA-256, geographic bounds and sampling provenance. The pure engine validates this contract. The live app **does not have** the 1,854,963,956-byte native raster (`ecosignal_georisk_v2_2024_risk_1m.tif`) or fixed reference cohort: the available verified package holds overlay graphics, model metadata and holdout evidence. Library retrieval found GeoRisk notebooks/package but not the numerical raster/reference. Display PNG colors, approximate 3D palette scores and unlocated holdout predictions are never used to supply unified inputs. This is an explicit data gap, not a completed live GeoRisk sampling integration.

Satellite exporter reads actual supplied weekly 2026-09-28 GeoTIFFs in EPSG:32617. Four tiles, 169 gzip chunks, 28,719,348 compressed bytes. Each chunk keeps native Float32 bands and 1-pixel halo; hashes verify fetched bytes. Coordinates use WGS84 to zone 17N, then native index transformation. Samples use medians of valid 3x3 source pixels (~60 m) with each clear_count>=1 and index in [-1,1]; overlap selection uses actual valid pixel counts. No resampling, palette inversion, 1km aggregation, quantized display grids or interpolated no-data. Clear counts are reported directly, not divided by assumed count to invent confidence. Acquisition dates retained: Sep29, Oct1, Oct4 2026; observed-at freshness uses last acquisition, with the compositing window reported. Land-cover matched references remain unavailable; anchors remain fixed PROVISIONAL.
