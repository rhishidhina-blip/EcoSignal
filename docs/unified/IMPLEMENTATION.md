## Method

Pure scoring schema version 1, engine EcoSignal-Unified-Provisional-v3.1.0, explicit configuration records. Weights: satellite .35, AQI .15, visible coverage .25, growth form 0 (context only), geomorphology .25. Biology is ONE domain. Satellite = .45 inverted NDVI(.2,.8) + .35 inverted NDMI(-.2,.5) + .20 BSI(-.3,.3), clamped 0–100. AQI =100*clip(AQI/300). Coverage inversion is provisional. Raw confidences are displayed separately; they are not calibrated scientific quality or overall confidence.

**Explicit method change from v20/v2:** the user selected the notebook's exploratory visible-coverage indicator as the entire biological domain (25%). The earlier 2:1 split is retired, not silently renormalized. Growth form is unweighted context, not a required score input. Its absence, uncertainty or category never changes the composite or domain completeness. No species tolerance or pollution ordering is assumed. Full score requires the four eligible weighted domains; the numerical source and CDF are now connected; complete scores still require eligible real biological, satellite and AirNow inputs. No partial total is published, and no incomplete score enters complete-score comparisons. Explicit zero-weight analysis inputs do not count or block ablations. Version 20's full source remains preserved at a72c9abb57982d587ab48b5ebf7d12fd909dcd14 and its saved Site version; frozen methodology and status are under docs/unified/v20/. Raw observation schema remains version 1: existing records are recomputed under the displayed v3 method, never converted to fabricated measurements.


GeoRisk is now integrated from the attached verified numerical package: ZIP SHA-256 97ee60bae227ee6b3924b5dfd27d6426be946ad95437d6b76c3c17ed67bf8de9; binary SHA-256 cb1bd7e15d47cbbd9d2a4282108061ca17b5d1600c9e13b78c29934f47309ec7. The numerical source has 1,473,136 valid samples on a 1536×1638 regular 20 m lattice in EPSG:32119, from the frozen GeoRisk V2 model, original 1 m features and hash-reverified common 2015/2022/2024 DEM coverage. Runtime verifies the complete 5,031,936-byte binary hash before sampling. Sampling fixtures stay in tests, never in observation records. The original full 1 m output raster remains absent, and is not required for this declared sampled-grid implementation.

WGS84 uses NAD83/GRS80 Lambert Conformal Conic with the supplied EPSG:32119 projection constants and null-shift datum convention, checked against all 24 supplied coordinate fixtures to <1 mm at those points. This is not a survey-grade datum accuracy claim. Round to nearest row/column offset from the declared first sample center; reject WGS84 bounds, out-of-grid and nodata65535. Decode uint16 little-endian, raw=value/10000, percentile=cdf_percent[value]. No interpolation/fill across gaps, PNG color inversion or area mean. The nearby sample is at most ~14.15 m away and is labelled as a nearby 20 m lattice point, not an exact arbitrary-location 1 m prediction.

Reference version **georisk-2024-native-features-20m-sampling-v1** is fixed across visitors and panning. The CDF is the complete valid regular sampled common-coverage cohort, not the original full 1 m pixel CDF. Independent software checks recompute all 10,001 CDF entries from the full decoded binary and verify valid count, monotonicity, nodata and score bounds. Model portability parity max1.574087e-7 and independent re-inference checks are preserved as supplied verification evidence; original DEMs are not here, so the Site integration independently checks sampling/data integrity, not full DEM/model re-inference. Quantization max error is 5e-5. Source year 2024 has year-only date precision; schema timestamp Jan1 is a year anchor, not a claimed acquisition day. Per-sample quality remains unknown. Global model evaluation metrics do not become individual confidence.

After explicit observation context confirmation, scan/imported-result, saved-record and selected-map panels automatically fetch and verify the numerical lattice and attach the actual sampled result with model/DEM/feature hashes, query/sample coordinates, source year, distance, row/column, raw value and reference. Restored records are re-sampled before allowing the terrain component into a score. The manual attach action refreshes satellite, AirNow and terrain together. Asynchronous results are rejected if observation context changes while loading. A confirmed real site with eligible other domains can now obtain a complete four-domain score. No partial total or invented observation is published.

Satellite exporter reads actual supplied weekly 2026-09-28 GeoTIFFs in EPSG:32617. Four tiles, 169 gzip chunks, 28,719,348 compressed bytes. Each chunk keeps native Float32 bands and 1-pixel halo; hashes verify fetched bytes. Coordinates use WGS84 to zone 17N, then native index transformation. Samples use medians of valid 3x3 source pixels (~60 m) with each clear_count>=1 and index in [-1,1]; overlap selection uses actual valid pixel counts. No resampling, palette inversion, 1km aggregation, quantized display grids or interpolated no-data. Clear counts are reported directly, not divided by assumed count to invent confidence. Acquisition dates retained: Sep29, Oct1, Oct4 2026; observed-at freshness uses last acquisition, with the compositing window reported.
